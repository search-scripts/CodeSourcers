# 🎮 CodeSourcers

> Repositório centralizado de scripts para diversos jogos, organizados por ano para fácil acesso e busca.

## 📋 Sobre o Projeto

O **CodeSourcers** é um repositório criado para facilitar a busca e organização de scripts de jogos. Aqui você encontra scripts organizados por ano, permitindo que você localize rapidamente o que precisa sem complicação.

## 🗂️ Estrutura do Repositório

```
CodeSourcers/
├── 2026/
│   ├── Jogo1/
│   │   └── script.lua
│   ├── Jogo2/
│   │   └── script.lua
│   └── ...
├── 2025/
│   └── ...
└── README.md
```

Cada pasta de ano contém subpastas com scripts específicos de diferentes jogos, todos testados e aceitos.

## 🔍 Como Usar

### Método 1: Navegação Manual
1. Acesse a pasta do ano desejado (ex: `2026/`)
2. Navegue pelas pastas de jogos disponíveis
3. Encontre e baixe o script que você precisa

### Método 2: Busca no GitHub
1. Use a barra de busca do GitHub (pressione `/` no repositório)
2. Digite o nome do jogo ou script que procura
3. Filtre por ano se necessário

### Método 3: Busca por Código
1. Acesse a aba "Code" do repositório
2. Use `Ctrl + F` (Windows/Linux) ou `Cmd + F` (Mac)
3. Digite palavras-chave relacionadas ao script

## 📌 Como Contribuir

Quer adicionar seus scripts? Siga estas etapas:

1. Fork este repositório
2. Crie uma branch para sua feature (`git checkout -b feature/NovoScript`)
3. Adicione seus scripts na pasta do ano correto
4. Commit suas mudanças (`git commit -m 'Adiciona script do JogoX'`)
5. Push para a branch (`git push origin feature/NovoScript`)
6. Abra um Pull Request
